# Security policy

Please report suspected vulnerabilities privately through GitHub's **Report a vulnerability** flow for this repository. Do not include credentials, private database content, or exploitable details in a public issue.

The latest released version receives security fixes. Reports should include the dbterm version, operating system, affected database or backup mode, reproduction steps, and the security impact. Ordinary bugs and feature requests belong in the public issue tracker.

dbterm handles database credentials and backup artifacts locally. Before sharing diagnostics, remove connection strings, usernames, file paths, SQL data, tokens, and encryption identities.
