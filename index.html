One interaction language

The shortest path from question to row.

dbterm is not a dashboard squeezed into a terminal. Each shortcut composes with the next, so exploration stays fast as the schema gets complicated.

01Ctrl P

Search the whole workspace

Fuzzy-find commands, tables, procedures, and recent SQL. Every result explains what it will do before you run it.

02F / Backspace

Follow relationships

Jump through declared foreign keys—including composite keys—then return to the exact table and row where you started.

03/ · C · V

Turn a cell into an answer

Copy a complete value, build typed AND filters, or search the selected column using the clipboard without leaving Results.

04Alt E

Export the right scope

Choose selected rows, the current page, or every filtered match. Long exports show progress and stay cancellable.

05+ · Ctrl +

Make dense data legible

Resize one column or scale the full table. Adjust preview limits and move between panels without reaching for a mouse.

06Esc / Ctrl C

Never wonder if it froze

Queries, imports, exports, and refreshes expose their state and accept cancellation instead of holding the interface hostage.

Before you connect

Good questions.

The complete guide covers every panel and shortcut.

Is the browser demo real?+

Yes. It loads SQLite compiled to WebAssembly and runs read-only SQL against an in-memory sample database. The sample data stays in your browser and is discarded when you leave.

Does dbterm need Go, Node, Python, or Java installed?+

No. dbterm is distributed as a single release binary for Linux, macOS, and Windows. Those frontend tools build this website only; they are not runtime requirements for dbterm.

Can it work with production databases?+

Yes, with the same discipline as any database client: use least-privilege credentials, review mutating SQL, and validate destructive operations away from production first.

Why another terminal SQL client?+

dbterm focuses on a tight end-to-end loop: connection, schema, query, relationship navigation, typed filtering, scoped export, and selected PostgreSQL/MySQL operations in one keyboard model. The comparison page also calls out where another tool may fit better.
