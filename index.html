Every interaction is designed to keep your hands on the keyboard and your context intact.

⌘ Ctrl P

Find anything

Fuzzy-search every command, database object, and recent query. Matches highlight as you type, with context before you act.

↗ F / Backspace

Follow the data

Jump across declared foreign keys—including composite keys—then return to the exact table and row you came from.

≡ / C V

Filter in place

Compose typed AND filters, copy a complete cell, or filter a column by the clipboard value without leaving Results.

⇩ Alt E

Export what matters

Export selected rows, the current page, or every matching row to CSV with progress, cancellation, and no silent overwrite.

◌ Esc / Ctrl C

Stay responsive

Queries, imports, exports, and refreshes show clear progress and can be cancelled without freezing the interface.

↔ + / Ctrl +

Shape the view

Resize one column, scale the full table, change preview limits, and move between panels entirely from the keyboard.

Good to know

Before you connect.

Still looking for something? The complete guide goes deeper.

Is dbterm really a single binary?+

Yes. End users do not need Go, Java, Python, or Node. Download the platform binary or use the installer and run dbterm.

Which operating systems are supported?+

Release binaries are published for Linux, macOS, and Windows on AMD64 and ARM64. Debian packages are also available.

Can I use it with production databases?+

Yes, with the same care as any SQL client: use least-privilege credentials and validate destructive statements outside production first.

Where is the full shortcut reference?+

The Guide covers setup, every workspace panel, keybindings, service actions, backups, imports, and troubleshooting. Alt+H also opens help inside dbterm.
