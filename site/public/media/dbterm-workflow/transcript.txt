00:00:13 — Stay on the keyboard.
Alt+T focuses Tables. Type a name, press Enter to open it, and Space to pin it.

00:00:19 — Forgot a shortcut?
Ctrl+P searches commands, tables and recent SQL. Try “backup”.

00:00:25 — Save a recovery copy.
Alt+B opens Instant Backup. Choose an absolute folder and a file name, then Create Backup.

00:00:32 — Wait for success.
This run created a SQLite snapshot and a completion manifest. SQLite needs no separate dump tool.

00:00:37 — Give “before” a name.
Alt+W opens Change Profiler. Press N, name your anchor, select the tasks table and capture it.

00:00:44 — Finish one task.

00:00:50 — Add the next one.

00:00:56 — Check the difference.
